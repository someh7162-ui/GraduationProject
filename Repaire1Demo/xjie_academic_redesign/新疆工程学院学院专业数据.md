# 新疆工程学院学院与专业数据说明

> 数据更新时间：2026-09-21  
> 用途：GraduationProject / Campus AI 注册页学院—专业联动、用户画像、推荐过滤、教务服务数据标准化。

## 1. 数据口径

本项目不把“学校官网出现过的所有历史专业”直接塞入注册页，而采用两层口径：

1. **学生注册口径**：以新疆工程学院招生网发布的《新疆工程学院2026年招生专业一览表（本、专科）》中的本科学院—专业分组为主。该表是最适合新生注册的当前招生口径。
2. **学院组织机构口径**：补充学校官网“教学机构”中存在、但未出现在2026普通本科招生专业分组中的学院，以及2026年6月新揭牌的3个学院。

学校2026年官方简介显示，学校目前有 **13个二级学院（另有2个产业学院）**，开设 **49个普通本科专业、4个职业本科专业**。需要注意的是，“学校现有专业总数”与“某一年度实际招生专业数”不是同一个概念：部分专业可能暂停当年招生、按大类招生，或正在进行学院归属调整。

因此，注册系统应优先保证“学生能选到自己当年真实录取的学院/专业”，而不是机械地把49个专业全部作为当年招生项展示。

## 3. 其他学院与教学单位

这些单位属于学校教学组织体系，但不应直接作为2026普通本科学生“专业归属”选项。

| 单位 | 注册页处理 | 说明 |
|---|---|---|
| 工程技能实训学院 | 教职工可选；学生不选 | 主要承担工程认知、基础工业、先进制造及创新实践课程 |
| 文化艺术学院 | 教职工可选；学生不选 | 官网明确属于公共课学院，目前没有自己的专业 |

## 4. 2026年新揭牌学院

2026年6月25日，新疆工程学院揭牌成立3个学院：

1. **地球科学与环境工程学院（玄武岩产业学院）**：面向能源资源绿色高效开发、生态环境综合治理、玄武岩新材料等方向。
2. **人工智能学院（机器人产业学院）**：面向智慧矿山、智慧能源、智能制造，建设“智能感知—智能决策—智能控制—智能装备”人才培养体系。
3. **应急管理学院**：依托安全科学与工程学院、经济管理学院运行，面向应急管理体系与能力现代化。

这3个学院已经正式揭牌，但截至2026年8月发布的招生专业一览表，普通本科招生专业仍按照原学院分组发布。因此本项目采取以下策略：

- 在完整学院数据中保留这3个学院；
- 辅导员/活动组织者等教职工身份可以看到这些学院；
- 普通学生注册暂不直接将其作为学院—专业选项；
- 等学校招生网或教务处正式发布专业归属调整后，再更新 `studentSelectable` 和 `majors`。

## 5. 2026年度拟新增专业：不要提前加入学生注册

学校于2026年9月4日召开新增本科专业专家论证会，论证了以下6个拟新增专业：

- 应急管理
- 光电信息科学与工程
- 地理空间信息工程
- 氢能科学与工程
- 低空技术与工程
- 航空服务艺术与管理

这些专业目前处于“拟新增/论证”状态，不能等同于已获批招生专业。注册系统不应提前开放给学生选择。

## 6. 注册页面设计规则

### 学生

注册时必须依次选择：

`学院 -> 专业 -> 年级`

规则：

- 学院仅显示2026招生专业表中有普通本科招生专业的学院；
- 专业选项根据学院动态联动；
- 更换学院后自动清空原专业，防止形成错误的学院—专业组合；
- 学生必须填写学院、专业和年级；
- 化学与环境工程学院同时保留“化工与制药类”和具体专业，以兼容专业分流前后学生。

### 辅导员 / 活动组织者

- 学院下拉框可包含学校完整学院组织数据；
- 专业不是必填项；
- 对于文化艺术学院、工程技能实训学院、新设学院等没有稳定本科专业招生映射的单位，专业保持为空。

## 7. 项目数据文件

推荐统一维护：

`frontend/src/data/xjieAcademics.js`

核心字段：

```js
{
  name: '信息工程学院',
  studentSelectable: true,
  status: 'active',
  majors: [
    { name: '计算机科学与技术', code: '080901', type: 'major' }
  ]
}
```

字段含义：

- `name`：学院正式名称；
- `studentSelectable`：是否允许普通本科学生注册时选择；
- `status`：`active`、`teaching_unit`、`public_course_college`、`continuing_education`、`new_2026_transition`；
- `majors`：该学院在当前注册口径下可选的专业/招生大类；
- `type`：`major` 或 `major_group`；
- `code`：教育部专业代码或招生大类代码；
- `note`：组织调整、招生状态等补充说明。

## 8. 数据维护原则

以后更新学院/专业数据时，优先级建议为：

1. 新疆工程学院当年招生专业一览表；
2. 经上级主管部门审核的当年招生章程；
3. 新疆工程学院学校官网“教学机构”和学校简介；
4. 各二级学院官网专业设置页面；
5. 对“拟新增专业”只记录状态，不提前作为可注册专业。

每年招生季建议至少核对一次数据，并更新 `updatedAt`。
